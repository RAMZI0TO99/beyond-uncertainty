# Workspace Source archive

`workspace-source/` retains direct Python and PowerShell Source files authored
during the 30-hour run and its continuation, including earlier refused,
superseded, spent and unrun versions. It is an archive, not the package's active
implementation or a designation that every file passed review.

The `.source` suffix keeps these files out of imports and test collection. Their
contents are byte-exact; original workspace paths and hashes are recorded in
the publication manifest. Absolute Windows paths, create-once outputs, old
bindings, imports and missing local evidence dependencies intentionally remain
unchanged. Do not run archived launchers, publishers, authoring helpers or spent
grants. New execution requires a reviewed successor and fresh authorization.

`workspace-snapshot/` contains the exact five Major036 Markdown documents and
checkpoint007, also with `.source` suffixes. Their local relative links are
historical workspace references, not a complete portable evidence tree. The
pre-publication wording records the author's preparation stage; later Root
publication and different creation acceptance are recorded separately under
`closeout-evidence/`.

The active project source is under `src/`, `scripts/` and `tests/`. Read the
[current closeout](CLOSEOUT_2026-10-03.md) for its practical status and remaining
work. No project tests or archived programs were run to prepare this publication.
